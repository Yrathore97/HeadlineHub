# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/Yrathore97/NewzWale/security/advisories/new).
Expect an initial response within 7 days.

## Scope

The live site at [newzwale.com](https://www.newzwale.com) and this repository.
API keys are stored as Cloudflare Worker secrets and are never committed — if
you find a credential in the git history, please report it as above.
